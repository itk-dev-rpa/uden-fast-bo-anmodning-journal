# Journalisering af anmodninger om uden fast bopæl

## Intro

The robot is responsible for journalising submission from the OS2Forms form about
not having an address for a period of time.

The robot reads submissions from an Outlook mailbox using the Graph API.
Submissions are journalised to KMD Nova on a new case and a task is created on the case.

## Know issuses

No known issues exists.
Both APIs are fairly stable.
